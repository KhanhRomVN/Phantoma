# Styling Rules

## 🚫 NGUYÊN TẮC SỐ 1: `var(--vscode-*)` BỊ CẤM TUYỆT ĐỐI

**Electron không phải VSCode webview** — tất cả `var(--vscode-*)` đều không tồn tại.
Phải chuyển sang biến MidnightBlue theme (có trong `tailwind.config.js`) hoặc Tailwind class.

## ⚠️ `var(--*)` LÀ DẠNG LỖI TRONG CẢ INLINE STYLES VÀ CLASSNAME

### Quy tắc cốt lõi:
1. **`var(--*)` trong className là SAI** — không có biến CSS nào được định nghĩa trong tailwind.config.js.
2. **`var(--*)` trong inline styles cũng là SAI** — phải dùng `$('--variable')` hoặc Tailwind class.
3. **Chỉ được dùng biến có trong `tailwind.config.js` và `MidnightBlue.ts`**.

### Cách sửa:
- `var(--variable)` trong className → Tailwind class từ mapping
- `var(--variable)` trong inline style → `$('--variable')` hoặc Tailwind class
- `color-mix(in srgb, var(--vscode-*), ...)` → `color-mix(in srgb, $('--variable'), ...)`

## 🚫 BIẾN KHÔNG TỒN TẠI

| Biến sai | Hành động |
|----------|-----------|
| `--secondary-bg` | ❌ Thay bằng `--background`, `--card-background` |
| `--primary-bg` | ❌ Thay bằng `--background` |
| `--primary-text` | ❌ Thay bằng `--text-primary` |
| `--secondary-text` | ❌ Thay bằng `--text-secondary` |
| `--border-color` | ❌ Thay bằng `--border` |
| `--input-bg` | ❌ Thay bằng `--input-background` |
| `--spacing-*` | ❌ Dùng Tailwind spacing |
| `--font-size-*` | ❌ Dùng Tailwind text size |
| `--border-radius*` | ❌ Dùng Tailwind rounded |

## Exception Cases
- `bg-[var(--error,rgba(...))]` — giữ nguyên fallback alpha, nhưng `--error` phải là biến tồn tại
- Animation keyframes — giữ trong `<style>` tag
