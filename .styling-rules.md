# Styling Rules

## 🚫 NGUYÊN TẮC SỐ 1: `var(--vscode-*)` BỊ CẤM TUYỆT ĐỐI

**Electron không phải VSCode webview** — tất cả `var(--vscode-*)` đều không tồn tại.
Phải chuyển sang biến MidnightBlue theme (được định nghĩa trong `src/renderer/src/theme/themes/MidnightBlue.ts` và expose qua `tailwind.config.js`).

## 📐 QUY TẮC ÁP DỤNG THEO LOẠI CODE

Có 3 môi trường viết style khác nhau, mỗi loại có cách xử lý riêng:

### 1. Tailwind ClassName (Ưu tiên số 1)
Dùng trực tiếp utility classes đã map sẵn trong `tailwind.config.js`.
*   ✅ `text-text-primary`, `bg-card-background`, `border-border`
*   ❌ `var(--text-primary)` trong className

### 2. Inline Styles trong JSX (`style={{...}}`)
Phải dùng helper function `$()` từ `@renderer/utils/color` để resolve giá trị runtime.
*   ✅ `color: $('--text-primary')`
*   ✅ `backgroundColor: $('--card-background')`
*   ❌ `color: 'var(--text-primary)'` (chuỗi tĩnh, không resolve được nếu theme đổi động)
*   ❌ Hardcoded hex `#e8ecf4` (vi phạm tính nhất quán theme)

### 3. CSS-in-JS Strings (`const styles = \`...\`` hoặc `<style>{...}`)
Đây là ngoại lệ duy nhất được phép dùng cú pháp `var(--...)` thuần CSS, **NHƯNG** chỉ với các biến MidnightBlue hợp lệ.
*   ✅ `color: var(--text-primary);`
*   ✅ `background: color-mix(in srgb, var(--warn) 50%, transparent);`
*   ❌ `color: #eab308;` (Hardcode - SAI)
*   ❌ `color: var(--vscode-warning);` (VSCode var - CẤM)
*   ❌ `color: var(--undefined-var);` (Biến lạ - SAI)

> **Lưu ý quan trọng:** Trong CSS string, KHÔNG THỂ dùng hàm JS `$()`. Hãy đảm bảo tên biến CSS khớp chính xác với key trong object `tailwind` của `MidnightBlue.ts` (đã được convert sang kebab-case khi inject vào DOM).

## 💡 MẸO XỬ LÝ ALPHA/TRANSPARENCY TRONG CSS STRINGS

Vì MidnightBlue dùng RGB format (`rgb(r,g,b)`), bạn **không thể** thêm alpha trực tiếp vào biến (ví dụ: `var(--warn)` không phải là rgba).
Hãy luôn dùng `color-mix()` để tạo độ trong suốt:

❌ **Sai:** `background: rgba(var(--warn), 0.1);` (CSS không hỗ trợ spread rgb var vào rgba)
✅ **Đúng:** `background: color-mix(in srgb, var(--warn) 10%, transparent);`
✅ **Đúng:** `border: 1px dashed color-mix(in srgb, var(--error) 50%, transparent);`
## 🎯 CHECKLIST KIỂM TRA NHANH (QUICK REFERENCE)

Trước khi commit code UI, hãy tự hỏi:
1.  **Có `var(--vscode-...)` nào không?** → ❌ Xóa ngay.
2.  **Trong JSX `style={{}}`, có hardcode hex (`#fff`) hoặc `var(--...)` thuần không?** → ✅ Đổi thành `$('--theme-var')`.
3.  **Trong chuỗi CSS (`<style>` hoặc template literal), có hardcode hex không?** → ✅ Đổi thành `var(--theme-var)`.
4.  **Trong chuỗi CSS, có cần transparency/alpha không?** → ✅ Dùng `color-mix(in srgb, var(--theme-var) %, transparent)`.
5.  **Tên biến CSS có nằm trong Whitelist ở trên không?** → Nếu không, tìm biến tương đương gần nhất.

## EXCEPTION CASES
- **Animation Keyframes:** Giữ nguyên trong `<style>` tag nếu phức tạp, nhưng màu sắc bên trong vẫn phải dùng `var(--theme-var)`.
- **Tailwind Arbitrary Values:** Tránh dùng `bg-[#hex]` hoặc `text-[var(--unknown)]`. Luôn ưu tiên class chuẩn từ config.

## AFTER READING THIS FILE

Khi AI đọc file này và thực hiện refactor/sửa lỗi styling:
1.  **Xác định ngữ cảnh:** Code đang ở dạng ClassName, Inline Style JS, hay CSS String?
2.  **Áp dụng đúng cú pháp:**
    *   ClassName → Tailwind utility (`text-warn`).
    *   Inline Style JS → Helper function (`$('--warn')`).
    *   CSS String → Native CSS variable (`var(--warn)`).
3.  **Kiểm tra tính hợp lệ:** Đối chiếu tên biến với danh sách Whitelist từ `MidnightBlue.ts`.
4.  **Không bao giờ Hardcode:** Mọi màu sắc phải truy xuất qua hệ thống theme để đảm bảo khả năng đổi theme (dark/light/high-contrast) sau này.
